## Deployment on GitHub Pages

1. Upload `index.html`, `favicon.svg` (or `favicon.png`), `sitemap.xml`, `robots.txt`, and `README.md` to your GitHub repository.
2. Replace `https://YOUR-USERNAME.github.io/` in `sitemap.xml` and `robots.txt` with your live GitHub Pages URL.
3. Go to **Repository Settings → Pages → Build and deployment** and select your main branch (`/` root).
4. In your **Appwrite Console**, go to **Overview → Platforms → Add Platform → Web** and add your live GitHub Pages hostname (without `https://`) to activate Live Email OTP.
